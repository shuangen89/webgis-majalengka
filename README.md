# WebGIS Kerentanan Gerakan Tanah Kabupaten Majalengka

Purwarupa WebGIS disertasi (S3 Teknik Geologi, Universitas Padjadjaran): peta kerentanan gerakan tanah skenario A–D, konsistensi kelas tinggi, ZKGT PVMBG (2016), litologi, jenis tanah, inventori 303 kejadian (2013–2023), sesar, dan titik pengamatan lapangan.

Dibangun dengan [Leaflet 1.9.4](https://leafletjs.com). Situs statis: cukup dibuka lewat GitHub Pages, tanpa server khusus.

Catatan: kelas kerentanan adalah peringkat relatif di dalam kabupaten (persentil luas 50/20/15/10/5%), bukan peta resmi.
